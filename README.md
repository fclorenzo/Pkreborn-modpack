# Pkreborn-modpack

My modpack for Pokémon Reborn, compatible with game version 19.6

## Contents

- Gone Fishing Mod (Reimplementation of Aironfaar's Gone Fishing without the need for that modbox's files): Automates the fishing mini-game by removing the need to press a button when a Pokémon bites.
- Shiny is better mod: Makes every shiny you encounter have at least 2 perfect (31) IVS & increased item chance.

## How to Install the Mods

1. Download the mod files by going to [the latest release page](https://github.com/fclorenzo/pkreborn-modpack/releases/latest).
2. Locate the `assets` section.
3. Under that section, you will find the mod files. Download the files for the features you wish to use.
4. Finally, create a folder called "Mods" inside the "patch" folder of your game, usually something like "Reborn-xxx-windows>patch" (where "xxx" corresponds to your game version), and paste the file(s) you just downloaded there.
